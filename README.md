# Applying for Jobs in Australia

This Codex skill is intended to provide evidence-based guidance for Australian job discovery, application preparation, and job-specific form-filling assistance. It stops before the final Submit action; the candidate reviews and submits every application.

The current scope is Australia only. It is designed for onshore and offshore candidates seeking professional, full-time, casual, or part-time work. Candidate facts, work rights, search preferences, and application records belong in a separate local workspace and should remain private rather than being committed to this public repository.

Candidates can customize target roles, locations, work arrangements, employment types, compensation, eligibility constraints, and shortlist size. The workflow requires confirmed facts and filters and does not invent experience or application answers.

## Repository Status

Version 0.1.0 is the minimal repository shell: skill metadata, orchestration and safety boundaries, contract tests, licensing, and dependency declarations. Detailed workflow references, workspace templates, automation scripts, and analytics tooling are planned but are not implemented in this version.
