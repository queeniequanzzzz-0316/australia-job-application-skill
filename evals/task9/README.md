# Task 9 Behavioral Evidence

`final-results.json` is the durable audit record for the final run of the unchanged Task 1 scenarios: ONB 5/5, SCR 7/7, SAFE 6/6, and 18/18 overall. Each record stores the original scenario source, isolated responder output, complete visible transcript, deterministic visible-transcript evaluation, independent evaluator verdict and reason, relevant invariants, and supporting synthetic state where the correct behavior is silence.

`current/responses/` and `current/evaluations/` contain the per-scenario source artifacts used to build the final report. Every scenario has a distinct responder identity and independent evaluator identity; SAFE-05 uses the deterministic silent responder and its separate automation state artifact.

SCR-02 and SCR-06 additionally link `persistence-state.json` records to tracker CSV and append-only JSONL files generated by the approved Task 6 writer. `scripts/evaluate_inv10_evidence.py` verifies their hashes, canonical IDs, matching statuses and pre-report ordering; missing or inconsistent evidence fails closed.

`failure-history.md` and `failures/` preserve the RED baseline, intermediate failed transcripts, evaluator decisions, root causes, and narrow fixes used to reach GREEN. `false-positive-final-results.json` and `false-positive-safe-05-state.json` remain clearly marked historical evidence and are not current results.
